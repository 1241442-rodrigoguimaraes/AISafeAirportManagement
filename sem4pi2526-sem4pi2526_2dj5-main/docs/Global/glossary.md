# AISafe Glossary

| Term                          | Definition                                                                                                  |
|-------------------------------|-------------------------------------------------------------------------------------------------------------|
| Air Control Area              | Controlled airspace region where flight operations are monitored and managed.                               |
| Air Control Area Boundaries   | Limits that define the geographic scope of an Air Control Area.                                             |
| Air Control Area ID           | Unique identifier of an Air Control Area.                                                                   |
| Air Control Area Minimum Fuel | Minimum fuel requirement associated with an Air Control Area.                                               |
| Air Infrastructure            | Domain area that groups airports, control areas, companies, nodes, and weather-related information.         |
| Air Transport Company         | Organization responsible for operating aircraft, flights, and routes.                                       |
| Aircraft                      | Physical aircraft operated by an Air Transport Company and associated with an Aircraft Model.               |
| Aircraft Configuration        | Domain area that groups aircraft models, engine models, makers, and related technical data.                 |
| Aircraft Country              | Country where an aircraft is registered.                                                                    |
| Aircraft Model                | Type of aircraft defined by its manufacturer, compatible engines, and key technical characteristics.        |
| Aircraft Model ID             | Unique identifier of an Aircraft Model.                                                                     |
| Aircraft Model Name           | Name assigned to an Aircraft Model.                                                                         |
| Aircraft Model Type           | Classification or type of an Aircraft Model.                                                                |
| Airport                       | Location where aircraft can take off and land, identified by standard aviation codes.                       |
| Airport IATA                  | IATA code that identifies an airport.                                                                       |
| Airport ICAO                  | ICAO code that identifies an airport.                                                                       |
| Al Safe User                  | Domain user with AISafe-specific profile information, security clearance, and skills assessment.            |
| Al Safe User Email            | Email address associated with an Al Safe User.                                                              |
| Altitude                      | Vertical position of a node or relevant location.                                                           |
| Approval Status               | Result status of a flight simulation approval process.                                                      |
| Arrival                       | Information describing the arrival of a flight leg.                                                         |
| Cabin Configuration           | Internal layout and seating configuration of an aircraft.                                                   |
| Collaborator ATCC             | Collaborator associated with an Air Transport Company.                                                      |
| Collaborator FCO              | Collaborator associated with air control operations in an Air Control Area.                                 |
| Coordinates                   | Geographic position used to locate a node.                                                                  |
| Crew Element                  | Crew member associated with an aircraft or flight operation.                                                |
| Departure                     | Information describing the departure of a flight leg.                                                       |
| Email Address                 | Email address used to identify or contact a system user.                                                    |
| Engine Model                  | Type of engine used by one or more aircraft models.                                                         |
| Engine Model Efficiency       | Efficiency information associated with an Engine Model.                                                     |
| Engine Model Fuel             | Fuel type or fuel-related information associated with an Engine Model.                                      |
| Engine Model ID               | Unique identifier of an Engine Model.                                                                       |
| Engine Model Name             | Name assigned to an Engine Model.                                                                           |
| Engine Model Power            | Power information associated with an Engine Model.                                                          |
| Engine Model Type             | Classification or type of an Engine Model.                                                                  |
| Expiry Date                   | Date until which a certification, authorization, or clearance remains valid.                                |
| Flight                        | Entity representing a flight operation, including identification, plan, and route.                          |
| Flight Designator             | Unique identifier assigned to a flight.                                                                     |
| Flight Plan                   | Operational plan of a flight.                                                                               |
| Flight Simulation             | Domain area that groups flights, flight plans, simulations, approvals, and reports.                         |
| Flight Type                   | Category or classification of a flight.                                                                     |
| Flights Simulation            | Simulation process involving one or more flights and producing an approval result and report.               |
| Fleet Management              | Domain area that groups aircraft, crew elements, registration, cabin configuration, and maintenance status. |
| Forecast                      | Prediction of future conditions relevant to flight operations.                                              |
| IATA Company Code             | IATA code that identifies an Air Transport Company.                                                         |
| ICAO Company Code             | ICAO code that identifies an Air Transport Company.                                                         |
| Leg                           | A segment of a flight between two points, departure and arrival.                                            |
| Maintenance Status            | Current maintenance condition of an aircraft.                                                               |
| Maker                         | Manufacturer of aircraft or engines.                                                                        |
| Maker Country                 | Country associated with a Maker.                                                                            |
| Maker Name                    | Name that identifies a Maker.                                                                               |
| Maximum Range                 | Maximum distance an Aircraft Model can operate under defined conditions.                                    |
| Node                          | Geographic point used in defining routes and segments.                                                      |
| Performance Specs             | Set of technical and operational characteristics of an aircraft or engine.                                  |
| Physics Data                  | Physical and technical data associated with an Aircraft Model.                                              |
| Pilot                         | User responsible for operating flights and certified for one or more Aircraft Models.                       |
| Registration                  | Unique identifier assigned to a physical aircraft.                                                          |
| Registration ID               | Unique registration identifier assigned to an Aircraft.                                                     |
| Role                          | Function or responsibility assigned to a user within the system.                                            |
| Route                         | Defined path followed by a flight.                                                                          |
| Security Clearance            | Authorized level of access granted to a user.                                                               |
| Segment                       | Portion of a flight leg connecting two geographic nodes.                                                    |
| Simulation Report             | Report produced by a flight simulation.                                                                     |
| Skills Assessment             | Evaluation of a user's competencies and qualifications.                                                     |
| System User                   | User account that provides system access and role information.                                              |
| User                          | Person with access to the system, identified by personal information.                                       |
| User And Access               | Domain area that groups users, roles, pilots, collaborators, and access-related information.                |
| Weather Data                  | Set of meteorological data associated with an Air Control Area.                                             |
| Weather Date                  | Date and time when Weather Data is recorded.                                                                |
| Wind Conditions               | Wind-related meteorological conditions associated with Weather Data.                                        |
