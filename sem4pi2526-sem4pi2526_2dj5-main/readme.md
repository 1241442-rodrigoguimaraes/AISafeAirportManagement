# Project AIControl

## 1. Description of the Project

This project was developed within the scope of the Integrated Project course unit of the fourth semester of the Bachelor's Degree in Computer Engineering at ISEP (2025/2026).
The main goal is to create an integrated solution for AlSafe, a startup that aims to modernize air traffic control systems, focusing on back-office management and flight
simulation to ensure air safety.

## 3. How to Build

Run the shell script `.eapli.base/build.sh` (Linux/Unix) or the bat script `.eapli.base/build.bat` (Windows) to build the project.

## 4. How to Execute Tests

Run the shell script `.eapli.base/build.sh` (Linux/Unix) or the bat script `.eapli.base/build.bat` (Windows) to execute all the tests (and build the project).

## 5. How to Run

Run the shell script `.eapli.base/run.sh` (Linux/Unix) or the bat script `.eapli.base/run.bat` (Windows) to run the project.

## 6. How to Install/Deploy into Another Machine (or Virtual Machine)

Run the shell script `.eapli.base/deploy.sh` (Linux/Unix) or the bat script `.eapli.base/deploy.bat` (Windows) to install the project in another machine.

## 7. How to Generate PlantUML Diagrams

To generate plantuml diagrams for documentation, execute the script (for the moment, only for linux/unix/macOS):

    ./generate-plantuml-diagrams.sh
